# საიტის რედაქტირება — გზამკვლევი არაპროგრამისტებისთვის

საიტის ყველა ტექსტი ინახება ჩვეულებრივ ტექსტურ ფაილებში. თქვენ მათ ხელით არ ეხებით: ასისტენტს ეუბნებით,
რა გინდათ, და ის აკეთებს. **ვერაფერს გააფუჭებთ**: ყველა ცვლილება ჯერ განსახილველად იგზავნება, საიტზე მხოლოდ
დამტკიცების შემდეგ ჩნდება და ყოველთვის შეიძლება დაბრუნდეს.

პირველად? ჯერ [SETUP.ka.md](SETUP.ka.md).

## ყოველდღიურად
1. გახსენით Claude (ჩანართი **Code**) ან Codex და აირჩიეთ საქაღალდე `Desktop/acton-tbilisi-website`.
2. ასისტენტი მოგესალმებათ და გეტყვით, გაქვთ თუ არა დაუსრულებელი ცვლილება.
3. დაწერეთ ჩვეულებრივად, ქართულად. მაგალითები:
   - „ფასი შეცვალე 1100 ლარზე“
   - „ზედა ზოლში დაწერე: ღია კარის დღე 5 დეკემბერს, 11:00“
   - „დაწერე სტატია შაბათის ბაზრობაზე, აი ჩემი ჩანაწერები: …“ (ან ჩასვით Facebook-ის პოსტის ტექსტი)
   - „_new-photos-ში 3 ფოტო ჩავაგდე, სტატიას დაუმატე“
   - „ამ კვირის კითხვაა: რატომ ვთამაშობთ?“ / „პარასკევის დასკვნა: …“
   - „FAQ-ში დაამატე: სადილი სახლიდან მოაქვთ“
   - „რა ინფორმაციაა ჯერ კიდევ დასაზუსტებელი?“
   - „რა მოუვიდა ჩემს გაგზავნილ ცვლილებებს?“
4. ასისტენტი გაჩვენებთ შედეგს თქვენს კომპიუტერზე (ბმული `http://localhost:4321/...`). თუ რამე არ მოგწონთ, უთხარით.
5. როცა მოგწონთ, უთხარით **„გაგზავნე“**. ის შეამოწმებს ყველაფერს და გაგზავნის განსახილველად.
   1-2 წუთში გამოჩნდება **ნახვის ბმული**, რომელიც შეგიძლიათ სხვებსაც გაუზიაროთ (ტელეფონზეც).
6. დამმტკიცებელი (ახლა: Otar) ნახავს და დააჭერს **Merge**-ს. საიტი 1 წუთში განახლდება.

Claude-ში მზა ბრძანებებიც არის (დაწერეთ `/`): `/start` დასაწყისი, `/preview` ნახვა, `/publish` გაგზავნა,
`/status` სტატუსი, `/undo` გაუქმება, `/new-article`, `/add-photo`, `/weekly-question`, `/add-faq`,
`/edit-content`, `/placeholders`. ბრძანებების გარეშეც ყველაფერი მუშაობს: უბრალოდ დაწერეთ.

## ფოტოები
- ჩააგდეთ ფაილი საქაღალდეში `acton-tbilisi-website/_new-photos` (ან გადმოიტანეთ პირდაპირ საუბარში).
- ასისტენტი გკითხავთ, ვინ არის ფოტოზე. სკოლის მოსწავლეების მშობლებს ხელშეკრულებით აქვთ გაცემული თანხმობა.
  სხვა ბავშვის ფოტოზე (სტუმარი, და-ძმა, საცდელი კვირა) საჭიროა ცალკე წერილობითი თანხმობა.
- ფოტოსთან ბავშვის სახელი არასდროს იწერება. ასისტენტი ფოტოდან ადგილმდებარეობის მონაცემებს ავტომატურად შლის.

## მნიშვნელოვანი წესები
- ასისტენტი არ იგონებს ფაქტებს (ფასები, თარიღები, სახელები, ციტატები). რაც არ იცის, გკითხავთ.
- **ყვითელი ჩარჩო „ნიმუში“** ნიშნავს, რომ ტექსტი ჯერ დასაზუსტებელია. ჩანს მხოლოდ თქვენს კომპიუტერზე და ნახვის
  ბმულზე, ნამდვილ საიტზე არა. როცა სწორ ინფორმაციას მისცემთ, ჩარჩო გაქრება.
- მშობლის ციტატა მხოლოდ მისი თანხმობით.
- დიზაინის, ფერების, ახალი გვერდის ან ფორმების ცვლილება Otar-თან შეთანხმებით.

## ასისტენტის გარეშე: პირდაპირ GitHub-ზე
1. GitHub-ზე გახსენით ფაილი, დააჭირეთ ფანქრის ხატულას (Edit), შეცვალეთ ტექსტი (ტექსტი ბრჭყალებში: `title: "…"`).
2. **Commit changes… → Create a new branch → Propose changes → Create pull request**.
3. დაელოდეთ მწვანე ნიშანს და ნახვის ბმულს. დამმტკიცებელი გამოაქვეყნებს.
