# საიტის რედაქტირება — გზამკვლევი არაპროგრამისტებისთვის

საიტის ყველა ტექსტი ინახება ჩვეულებრივ ტექსტურ ფაილებში, საქაღალდეში `src/content/`.
ცვლილება ჯერ „წინასწარ ნახვაზე“ (preview) ჩანს და მხოლოდ დადასტურების შემდეგ ხვდება ნამდვილ საიტზე.
ვერაფერს გააფუჭებთ: ყველა ცვლილება ინახება და შეიძლება დაბრუნდეს.

## გზა 1: AI აგენტით (ყველაზე მარტივი)
1. გახსენით რეპოზიტორია Claude Code-ში (ან სხვა AI აგენტში: Codex, Cursor…).
2. დაწერეთ ჩვეულებრივად, ქართულად, მაგალითად:
   - „ფასი შეცვალე 1100 ლარზე“
   - „დაამატე ბლოგპოსტი შაბათის ლაშქრობაზე, აი ტექსტი: …“
   - „ამ კვირის კითხვაა: რატომ ვთამაშობთ?“
   - „პარასკევის დასკვნა: …“
   - „რა ინფორმაციაა ჯერ კიდევ დასაზუსტებელი?“
3. აგენტი თავად იპოვის ფაილს, შეცვლის, შეამოწმებს და შექმნის Pull Request-ს. Claude Code-ში მზა ბრძანებებიც არის:
   `/edit-content`, `/new-post`, `/weekly-question`, `/add-faq`, `/add-photo`, `/placeholders`.
4. Pull Request-ში ნახავთ preview ბმულს. თუ მოგწონთ, დააჭირეთ **Merge**. საიტი 1 წუთში განახლდება.

## გზა 2: პირდაპირ GitHub-ზე, ბრაუზერიდან
1. GitHub-ზე გახსენით ფაილი, მაგალითად `src/content/pages/ka/home.yaml`.
2. დააჭირეთ ფანქრის ხატულას (Edit), შეცვალეთ ტექსტი.
3. **Commit changes… → Create a new branch → Propose changes → Create pull request**.
4. დაელოდეთ მწვანე ნიშანს (შემოწმება) და preview ბმულს, შემდეგ **Merge**.

## მნიშვნელოვანი წესები
- **ტექსტი ყოველთვის ბრჭყალებში:** `title: "ფასი: 1000 ₾"`. ორწერტილი და მძიმე ბრჭყალების გარეშე ფაილს აზიანებს.
- **`placeholder: true`** ნიშნავს, რომ ტექსტი ნიმუშია და დასაზუსტებელია. როცა დაადასტურებთ, ეს ხაზი წაშალეთ.
- **ბავშვის ფოტო:** სკოლის მოსწავლეების მშობლებს ხელშეკრულებით აქვთ გაცემული თანხმობა (`consent: signed`). სხვა ბავშვის ფოტოზე (სტუმარი, საცდელი კვირა) საჭიროა ცალკე წერილობითი თანხმობა. ფოტოსთან ბავშვის სახელი არასდროს.
- მშობლის ციტატა მხოლოდ მისი თანხმობით (`approved: true`).
