# Adding a language (e.g. English)

The site is Georgian-only today, but structured so a second language is additive:

1. `astro.config.mjs` → `i18n.locales: ['ka', 'en']` (Georgian stays default, without a URL prefix).
2. `src/i18n/ui.ts` → copy the `ka` block to `en` and translate.
3. Copy content folders: `src/content/*/ka/` → `src/content/*/en/`, `settings/ka.yaml` → `settings/en.yaml`,
   `pages/ka/*.yaml` → `pages/en/*.yaml`, and translate. (`photos.yaml` alt texts are Georgian; add `altEn` if needed.)
4. Pages: create `src/pages/en/` versions that call the same components with `lang="en"`. The helpers
   `getLocalized(collection, lang)`, `getSettings(lang)`, `getPage(collection, lang)` and `t(lang)` already take a language;
   components currently use the default, so pass `lang` through as a prop when you do this.
5. Set `<html lang>` from the locale in `BaseLayout`, add a language switch to `Header`, and `hreflang` links.
