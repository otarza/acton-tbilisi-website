# პირველი მომზადება (ერთხელ, ~20 წუთი)

ეს გზამკვლევი პარტნიორებისა და სკოლის გუნდისთვისაა, ვინც საიტს AI ასისტენტით შეცვლის.
პროგრამირება არ გჭირდებათ. ყველა ტექნიკურ ნაბიჯს ასისტენტი თავად გააკეთებს ან ნაბიჯ-ნაბიჯ აგიხსნით.

## 1. GitHub-ის ანგარიში
GitHub არის ადგილი, სადაც საიტის ფაილები ინახება.
1. გახსენით https://github.com/signup და შექმენით უფასო ანგარიში (ან შედით არსებულით).
2. გაუგზავნეთ Otar-ს თქვენი GitHub-ის სახელი (username).
3. ელფოსტაზე მოგივათ მოწვევა „acton-tbilisi-website“-ზე. დააჭირეთ **Accept invitation**.

## 2. AI ასისტენტი
აირჩიეთ ერთ-ერთი:
- **Claude** (რეკომენდებული): ჩამოტვირთეთ https://claude.ai/download, შედით ანგარიშით და გახსენით ჩანართი **Code**.
- **Codex**: ჩამოტვირთეთ ChatGPT/Codex-ის დესკტოპ აპლიკაცია და შედით ანგარიშით.

## 3. პროექტის გადმოწერა
1. ასისტენტში დაიწყეთ ახალი სესია და საქაღალდედ აირჩიეთ **Desktop** (სამუშაო მაგიდა).
2. ჩასვით ეს შეტყობინება და გაგზავნეთ:

   ```
   გადმოწერე ეს პროექტი ჩემს კომპიუტერზე, საქაღალდეში Desktop: https://github.com/otarza/acton-tbilisi-website
   თუ რამე აკლია (git, Node.js, GitHub CLI), ნაბიჯ-ნაბიჯ დამეხმარე, ქართულად. შემდეგ მითხარი, რომელი საქაღალდე გავხსნა.
   ```
3. თუ გამოჩნდება ფანჯარა „Install Command Line Developer Tools“, დააჭირეთ **Install** და დაელოდეთ.
4. როცა ასისტენტი გეტყვით, დაიწყეთ **ახალი სესია** და საქაღალდედ აირჩიეთ `Desktop/acton-tbilisi-website`.

## 4. პირველი საუბარი
ახალ სესიაში ასისტენტი თავად მოგესალმებათ. დაწერეთ **„დამეხმარე“**. ის შეამოწმებს, ყველაფერი მზადაა თუ არა:
- თუ საჭიროა **Node.js**, გაგიგზავნით ბმულს (https://nodejs.org → LTS → macOS Installer).
- **GitHub-ში შესვლისთვის** ბრაუზერი გაიხსნება: ჩაწერეთ ის 8-ასოიანი კოდი, რომელსაც ასისტენტი გაჩვენებთ,
  და დააჭირეთ **Authorize**.
- თქვენს სახელს და GitHub-ის ელფოსტას გკითხავთ (ცვლილებებზე ავტორად რომ ჩანდეთ).

როცა ასისტენტი იტყვის „✅ ყველაფერი მზადაა“, შეგიძლიათ დაიწყოთ. შემდეგ: [EDITING-GUIDE.ka.md](EDITING-GUIDE.ka.md).
